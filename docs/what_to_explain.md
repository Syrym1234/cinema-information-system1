# Мұғалім алдында қысқаша түсіндіру

**№6:** Мен `CREATE DATABASE` арқылы CinemaSchoolDB қорын құрдым. `CREATE TABLE` арқылы 7 кесте жасадым. `PRIMARY KEY` әр жолды бірегей ажыратады, `FOREIGN KEY` фильмді жанрмен, сеансты залмен байланыстырады. `INSERT` дерек қосады, `UPDATE` өзгертеді, `DELETE` жояды. `WHERE` шартымен тек қажетті жолды өзгертуге болады.

**№7:** `SELECT` деректерді алады, `WHERE` сүзеді. `ORDER BY start_at ASC` сеансты ерте уақыттан кешке қарай сұрыптайды. `ORDER BY price DESC` қымбат бағадан арзанға қарай сұрыптайды. `GROUP BY` топтайды, `COUNT` санайды, `SUM` түсімді қосады, `HAVING` топ нәтижесіне шарт қояды.

**Сайт байланысы:** Браузер `/api/sessions` сұранысын жібереді -> Node.js сервер оны өңдейді -> SQL Server сұрыпталған нәтижені қайтарады -> браузер көрсетеді. Бұл «экрандағы мәтінді қолмен ауыстыру» емес.

**Ескерту:** Node.js серверіндегі желілік код, SQL параметрлері және билет сатылған орынды тексеру оқу лабораториясындағы SQL тақырыптарының бөлігі емес. Олар сайт жұмыс істеуі үшін қажет техникалық код. Оларды мұғалім сұраса жеке түсіндіруге болады.

**Шектеу:** Осы оқу нұсқасында төлем, QR, топтық брондау жоқ. Билет сатып алу тек **демонстрация**, нақты ақша алынбайды.
