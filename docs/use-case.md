# Use case — Кинотеатр ақпараттық жүйесі

Актер: **Көрермен**.

1. Көрермен сайтты ашады.
2. Фильмді немесе сеансты іздейді.
3. Сеанстарды уақыт/баға бойынша сұрыптайды.
4. Сеансты таңдап, бос орындарды көреді.
5. Орын таңдап, аты-жөнін және email енгізеді.
6. Жүйе `Tickets` кестесіне жаңа билет сақтайды.
7. Көрермен демо билет нөмірін алады.

Актер: **Әкімші (SQL Server Management Studio-де)**.

1. Кестелер құрады (`CREATE TABLE`).
2. Тест деректерін енгізеді (`INSERT`).
3. Деректерді өзгертеді/жояды (`UPDATE`, `DELETE`).
4. Есептер шығарады (`SELECT`, `WHERE`, `GROUP BY`, `HAVING`).
