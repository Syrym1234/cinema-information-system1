01-08 суреттері - нақты API-ге fetch жіберетін, есепке арналған HTTP тест клиентінің скриншоттары. Бұл Postman қолданбасының терезесі емес. 09-15 және 17 - нақты веб-қолданбадан алынған. 16 - өзгертілмеген Newman орындалу журналындағы мәндердің көрнекі көрсетілімі; ол да Postman терезесі деп белгіленбейді.

`capture-manifest.json` нақты сұраныстарды, body, статус, жауап, түсіру уақытын және уақытша фильмдердің тазаланғанын сақтайды. Postman коллекциясының толық нәтижесі бір деңгей жоғарыдағы `newman-results.json` файлында бар.

Қайта түсіру: сервер іске қосылғанда `node tools/capture_report_screenshots.cjs`. Playwright пакеті қажет (`PLAYWRIGHT_MODULE` арқылы орнын көрсетуге болады). PDF қайта құру: `python tools/build_lab10_report.py` (ReportLab, Pillow, pypdf және Windows Arial/Consolas қаріптері қажет).
