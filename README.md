# CINÉMA LAB — Кинотеатрдың ақпараттық жүйесі

**№5, №6, №7 зертханалықтарға арналған түсінікті нұсқа.**

Бұл жобада тек негізгі SQL тақырыптары демонстрацияланады: `CREATE TABLE`, `INSERT`, `UPDATE`, `DELETE`, `SELECT`, `WHERE`, `AND`, `BETWEEN`, `DISTINCT`, `ORDER BY`, `GROUP BY`, `HAVING`, `COUNT`, `AVG`, `MIN`, `MAX`, `SUM`. №6 талабына сәйкес PK, FK, `NOT NULL`, `UNIQUE`, `CHECK` бар.

## 1. SQL Server / SSMS

SSMS орнатылып, SQL Server-ге қосылғаннан кейін **New Query** ашып, төмендегі файлдардың мазмұнын осы ретпен орындаңыз:

1. `sql/01_create_database.sql` — деректер қорын және кестелерді құру (бір рет қана).
2. `sql/02_insert_data.sql` — бастапқы деректерді енгізу (бір рет қана).
3. `sql/05_check.sql` — нәтижені тексеру (қайта орындауға болады).
4. `sql/03_lab6_insert_update_delete.sql` — №6 практикалық жұмыс (қайта орындауға болады; алдымен деректен тексеріңіз).
5. `sql/04_lab7_select_sort_group.sql` — №7 сұраныстар (көп рет орындауға болады).

**Маңызды:** 01 және 02 файлдарын қайта-қайта орындамаңыз: біріншіде `Database already exists`, екіншісінде қайталанған деректер немесе UNIQUE шектеу қателері болуы мүмкін. Бұл скрипттер ешқандай ескі базаңызды өшірмейді.

## 2. VS Code-та сайтты іске қосу

Node.js орнатылуы керек. Жоба қалтасын VS Code арқылы ашып, Terminal -> New Terminal таңдаңыз:

```powershell
Copy-Item .env.example .env
npm install
npm test
npm start
```

`.env` файлын ашып, SQL Server қосылымының дұрыс параметрлерін көрсетіңіз: `DB_SERVER`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` және `DB_PORT`. `DB_USER=sa` үлгісі **тек SQL Server Authentication** қосылған кезде жұмыс істейді; Windows Authentication пайдалансаңыз, параметрлерді бөлек бейімдеу қажет.

Браузерде <http://localhost:3000> ашыңыз.

## 3. Жоба қалай жұмыс істейді?

`public/app.js` -> `GET /api/sessions` -> `server/index.js` -> SQL Server-ге `SELECT ... WHERE ... ORDER BY ...` -> нәтиже браузерде көрінеді. SQL-дағы сорт `server/filters.js` ішіндегі рұқсат етілген нұсқалармен таңдалады. Брондау демосы `Tickets` кестесіне жаңа жол жазады; `UNIQUE(session_id,seat_number)` екі адамға бір орынды сатуға мүмкіндік бермейді.
